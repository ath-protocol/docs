description: "一段话、一张图、一个选择——然后开始构建。"
---

**ATH（Agent Trust Handshake，Agent 信任握手）** 是一个协议，允许 AI Agent 访问用户在外部服务上的数据——但**只有在服务和用户都同意之后**才行。它是 AI Agent 时代的 OAuth。

```mermaid
sequenceDiagram
    participant Agent as 🤖 AI Agent
    participant Service as 🏢 你的应用
    participant User as 👤 用户

    Note over Agent,Service: 阶段 A：服务是否信任这个 Agent？
    Agent->>Service: "我是 TravelBot，可以访问日历数据吗？"
    Service-->>Agent: "已批准只读日历访问权限。"

    Note over Agent,User: 阶段 B：用户是否同意？
    Agent->>User: "请授权我读取你的日历"
    User-->>Service: "是的，我允许只读访问"

    Note over Agent,Service: ✅ 双方都同意 → Agent 获得令牌
    Agent->>Service: 读取日历（使用令牌）
    Service-->>Agent: 日历事件
```

就是这样。两道关卡，都必须通过。Agent 获得的权限是被批准范围的**交集**——永远不会更多。
