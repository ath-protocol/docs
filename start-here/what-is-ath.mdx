description: "One paragraph, one diagram, one decision — then let's get building."
---

**ATH (Agent Trust Handshake)** is a protocol that lets AI agents access your users' data on external services — but **only after both the service AND the user say yes**. It's OAuth for the agent era.

```mermaid
sequenceDiagram
    participant Agent as 🤖 AI Agent
    participant Service as 🏢 Your App
    participant User as 👤 User

    Note over Agent,Service: Phase A: Does the service trust this agent?
    Agent->>Service: "I'm TravelBot. Can I access calendar data?"
    Service-->>Agent: "Approved for read-only calendar access."

    Note over Agent,User: Phase B: Does the user consent?
    Agent->>User: "Please approve me to read your calendar"
    User-->>Service: "Yes, I allow read-only access"

    Note over Agent,Service: ✅ Both said yes → Agent gets a token
    Agent->>Service: Read calendar (with token)
    Service-->>Agent: Calendar events
```

That's it. Two gates, both must pass. The agent gets the **intersection** of what was approved — never more.
