## Gateway Mode — Complete Walkthrough

```python
from ath import ATHGatewayClient
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives import serialization

# 1. Generate a key pair (use persistent key in production)
private_key = ec.generate_private_key(ec.SECP256R1())
pem = private_key.private_bytes(
    serialization.Encoding.PEM,
    serialization.PrivateFormat.PKCS8,
    serialization.NoEncryption(),
).decode()

# 2. Create the client
with ATHGatewayClient(
    url="http://localhost:3000",
    agent_id="https://my-agent.example.com/.well-known/agent.json",
    private_key=pem,
    key_id="my-key-2024",
) as client:
    # 3. Discover available providers
    discovery = client.discover()
    for provider in discovery.supported_providers:
        print(f"  {provider.provider_id}: {provider.available_scopes}")

    # 4. Register the agent
    registration = client.register(
        developer={"name": "MyDev", "id": "mydev-001"},
        providers=[
            {"provider_id": "github", "scopes": ["read:user", "repo"]},
        ],
        purpose="Access GitHub repos on behalf of users",
    )
    print(f"Status: {registration.agent_status}")
    print(f"Client ID: {registration.client_id}")

    # 5. Start authorization
    auth = client.authorize("github", ["read:user"])
    print(f"Please visit: {auth.authorization_url}")
    print(f"Session: {auth.ath_session_id}")

    # 6. After user completes OAuth, exchange for token
    code = "authorization-code-from-callback"
    token = client.exchange_token(code, auth.ath_session_id)
    print(f"Access token: {token.access_token}")
    print(f"Effective scopes: {token.effective_scopes}")

    # 7. Call APIs through the proxy
    user = client.proxy("github", "GET", "/user")
    print(f"GitHub user: {user}")

    repos = client.proxy("github", "GET", "/user/repos?per_page=5")
    print(f"Repos: {repos}")

    # 8. Revoke when done
    client.revoke()
    print("Token revoked")
```

## Async Client

For async applications (FastAPI, aiohttp, etc.):

```python
import asyncio
from ath import AsyncATHGatewayClient

async def main():
    async with AsyncATHGatewayClient(
        url="http://localhost:3000",
        agent_id="https://my-agent.example.com/.well-known/agent.json",
        private_key=pem,
    ) as client:
        discovery = await client.discover()
        registration = await client.register(
            developer={"name": "MyDev", "id": "mydev-001"},
            providers=[{"provider_id": "github", "scopes": ["read:user"]}],
            purpose="Testing",
        )
        
        auth = await client.authorize("github", ["read:user"])
        # ... user completes OAuth ...
        
        token = await client.exchange_token(code, auth.ath_session_id)
        user = await client.proxy("github", "GET", "/user")
        
        await client.revoke()

asyncio.run(main())
```

## Native Mode

```python
from ath import ATHNativeClient

with ATHNativeClient(
    url="https://service.example.com",
    agent_id="https://my-agent.example.com/.well-known/agent.json",
    private_key=pem,
) as client:
    # discover() learns api_base from /.well-known/ath-app.json
    client.discover()

    client.register(
        developer={"name": "MyDev", "id": "mydev-001"},
        providers=[{"provider_id": "default", "scopes": ["read"]}],
        purpose="Access service data",
    )

    auth = client.authorize("default", ["read"])
    # ... user completes OAuth ...
    client.exchange_token(code, auth.ath_session_id)

    # api() calls {api_base}/{path} directly
    data = client.api("GET", "/resources")
```

## Key Classes

### `ATHGatewayClient` / `AsyncATHGatewayClient`

| Method | Returns | Description |
|--------|---------|-------------|
| `discover()` | `DiscoveryDocument` | Fetch gateway catalog |
| `register(...)` | `AgentRegistrationResponse` | Register agent (Phase A) |
| `authorize(provider, scopes, ...)` | `AuthorizationResponse` | Start user OAuth (Phase B) |
| `exchange_token(code, session_id)` | `TokenResponse` | Exchange for ATH token |
| `proxy(provider, method, path, body=None)` | `dict` or `str` | Call API through proxy |
| `revoke()` | `None` | Revoke current token |

### Credential Persistence

```python
# Save credentials after registration
client.save_credentials("credentials.json")

# Load credentials in a later session
client.load_credentials("credentials.json")

# Or set manually
client.set_credentials(client_id="ath_abc123", client_secret="ath_secret_...")
client.set_token("ath_tk_...")
```

## Error Handling

```python
from ath import ATHError

try:
    data = client.proxy("github", "GET", "/user")
except ATHError as e:
    print(f"ATH Error [{e.code}]: {e.message}")
    print(f"HTTP Status: {e.status}")
    print(f"Details: {e.details}")

    if e.code == "TOKEN_EXPIRED":
        # Re-authorize and get a new token
        pass
    elif e.code == "NOT_REGISTERED":
        # Need to register first
        pass
```

### Client-Side Error Codes

In addition to server error codes, the Python SDK raises these locally:

| Code | When |
|------|------|
| `NOT_REGISTERED` | Calling `authorize` / `exchange_token` without registration |
| `NO_TOKEN` | Calling `proxy` / `api` without a token |
| `INVALID_RESPONSE` | Server returned non-JSON success response |

## Pydantic Types

All response objects are **Pydantic v2 models**, so you get IDE autocompletion and validation:

```python
from ath import DiscoveryDocument, TokenResponse, ScopeIntersection

# Type-safe access to response fields
token: TokenResponse = client.exchange_token(code, session_id)
intersection: ScopeIntersection = token.scope_intersection
print(intersection.effective)  # ["read:user"]
```
