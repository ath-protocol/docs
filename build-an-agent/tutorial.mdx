Your agent needs to access an API that's protected by ATH. This tutorial walks you through connecting to the demo shop and placing an order.

**What you'll build:** An agent that discovers the shop, gets user approval, and buys products.

**Prerequisites:** The [demo running](/start-here/run-the-demo) (or any ATH-protected service). Node.js 20+ or Python 3.10+.

---

## The 7 Commands

Every ATH agent interaction follows this sequence:

```
discover → register → authorize → [user consents] → token → use API → revoke
```

Let's do each one. Pick your language:

<Tabs>
  <Tab title="TypeScript SDK">
    ```typescript
    import { ATHNativeClient } from "@ath-protocol/client";
    import { generateKeyPair } from "jose";

    const { privateKey } = await generateKeyPair("ES256");

    const client = new ATHNativeClient({
      url: "https://ath-shop.local:3000",
      agentId: "https://agent.ath.local:4000/.well-known/agent.json",
      privateKey,
    });

    // 1. Discover
    const discovery = await client.discover();
    console.log("Scopes available:", discovery.auth.scopes_supported);

    // 2. Register
    const reg = await client.register({
      developer: { name: "My Agent", id: "my-agent-dev" },
      providers: [{ provider_id: "ath-shop", scopes: ["products:read", "cart:write", "orders:write"] }],
      purpose: "AI shopping assistant",
    });
    console.log("Approved:", reg.agent_status);

    // 3. Authorize
    const auth = await client.authorize("ath-shop", ["products:read", "cart:write", "orders:write"]);
    console.log("Send user to:", auth.authorization_url);
    // → User opens URL in browser, sees consent page, clicks Authorize

    // 4. Token (after user approves)
    const token = await client.exchangeToken("exchange", auth.ath_session_id);
    console.log("Got token! Scopes:", token.effective_scopes);

    // 5. Use the API
    const products = await client.api("GET", "/products");
    console.log("Products:", products);

    await client.api("POST", "/cart/add", { productId: products.products[0].id, quantity: 2 });
    await client.api("POST", "/orders", { shippingAddress: "123 Agent St" });

    // 6. Revoke
    await client.revoke();
    ```
  </Tab>
  <Tab title="Python SDK">
    ```python
    from ath import ATHNativeClient
    from cryptography.hazmat.primitives.asymmetric import ec
    from cryptography.hazmat.primitives import serialization

    # Generate key (use persistent key in production)
    key = ec.generate_private_key(ec.SECP256R1())
    pem = key.private_bytes(
        serialization.Encoding.PEM,
        serialization.PrivateFormat.PKCS8,
        serialization.NoEncryption(),
    ).decode()

    with ATHNativeClient(
        url="https://ath-shop.local:3000",
        agent_id="https://agent.ath.local:4000/.well-known/agent.json",
        private_key=pem,
    ) as client:
        # 1. Discover
        discovery = client.discover()
        print("Scopes:", discovery.auth.scopes_supported)

        # 2. Register
        reg = client.register(
            developer={"name": "My Agent", "id": "my-agent-dev"},
            providers=[{"provider_id": "ath-shop", "scopes": ["products:read", "cart:write", "orders:write"]}],
            purpose="AI shopping assistant",
        )
        print("Approved:", reg.agent_status)

        # 3. Authorize
        auth = client.authorize("ath-shop", ["products:read", "cart:write", "orders:write"])
        print("Send user to:", auth.authorization_url)
        # → User opens URL, approves

        # 4. Token
        token = client.exchange_token("exchange", auth.ath_session_id)
        print("Got token! Scopes:", token.effective_scopes)

        # 5. Use API
        products = client.api("GET", "/products")
        client.api("POST", "/cart/add", {"productId": products["products"][0]["id"], "quantity": 2})
        client.api("POST", "/orders", {"shippingAddress": "123 Agent St"})

        # 6. Revoke
        client.revoke()
    ```
  </Tab>
  <Tab title="athx CLI">
    ```bash
    SERVICE="https://ath-shop.local:3000"
    AGENT="https://agent.ath.local:4000/.well-known/agent.json"

    # 1. Discover
    athx discover --mode native --service $SERVICE --agent-id $AGENT

    # 2. Register
    athx register --mode native --service $SERVICE --agent-id $AGENT \
      --provider ath-shop --scopes "products:read,cart:write,orders:write"

    # 3. Authorize
    athx authorize --mode native --service $SERVICE --agent-id $AGENT \
      --provider ath-shop --scopes "products:read,cart:write,orders:write"
    # → Open the authorization_url in browser, log in, click Authorize

    # 4. Token
    athx token --mode native --service $SERVICE --agent-id $AGENT \
      --code exchange --session <session_id from step 3>

    # 5. Use API
    athx proxy --mode native --service $SERVICE --agent-id $AGENT \
      ath-shop GET /products

    athx proxy --mode native --service $SERVICE --agent-id $AGENT \
      ath-shop POST /cart/add --body '{"productId":"1","quantity":2}'

    athx proxy --mode native --service $SERVICE --agent-id $AGENT \
      ath-shop POST /orders --body '{"shippingAddress":"123 Agent St"}'

    # 6. Revoke
    athx revoke --mode native --service $SERVICE --agent-id $AGENT --provider ath-shop
    ```
  </Tab>
</Tabs>

## What Each Step Does

| Step | What happens | If you skip it |
|:----:|-------------|---------------|
| **Discover** | Learn what the service offers | You won't know the available scopes or endpoints |
| **Register** | Service decides if your agent is allowed | `AGENT_NOT_REGISTERED` error on everything else |
| **Authorize** | Get a URL for user consent | No user consent = no token |
| **Token** | Get an access token (scoped) | Can't call any API |
| **Use API** | Call the service with your token | — |
| **Revoke** | Clean up (optional but polite) | Token expires naturally, but best practice to revoke |

## Gateway Mode vs Native Mode

The code above uses **native mode** (agent connects directly to the service). For **gateway mode**, just change the URL and use gateway-specific methods:

<Tabs>
  <Tab title="TypeScript (Gateway)">
    ```typescript
    import { ATHGatewayClient } from "@ath-protocol/client";

    const client = new ATHGatewayClient({
      url: "http://gateway.ath.local:4001",  // gateway URL, not service
      agentId: "https://agent.ath.local:4000/.well-known/agent.json",
      privateKey,
    });

    await client.discover();  // Gets gateway's provider list
    // ... register, authorize, token same as before ...
    
    // Use proxy() instead of api()
    const products = await client.proxy("ath-shop", "GET", "/products");
    ```
  </Tab>
  <Tab title="athx CLI (Gateway)">
    ```bash
    GW="http://gateway.ath.local:4001"
    
    athx discover --gateway $GW --agent-id $AGENT
    athx register --gateway $GW --agent-id $AGENT --provider ath-shop --scopes "products:read"
    athx authorize --gateway $GW --agent-id $AGENT --provider ath-shop --scopes "products:read"
    athx token --gateway $GW --agent-id $AGENT --code <code> --session <session>
    athx proxy ath-shop GET /products --gateway $GW --agent-id $AGENT
    ```
  </Tab>
</Tabs>
